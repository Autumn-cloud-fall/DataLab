# Data Lab

本实验通过受限的整数运算和 IEEE 754 单精度浮点数位级操作，练习二进制表示、补码、移位、溢出与舍入。

## 需要完成的内容

只修改 `bits.c` 中 P1–P19 的函数体。每道题注释给出了允许使用的运算符、最大运算数、参数范围与分值。整数题不得使用控制语句、宏、函数调用、强制类型转换或 `unsigned` 等额外类型；浮点题可使用整数/无符号整数、条件和循环，但仍不得使用浮点类型、浮点常量或浮点运算。

## 整数机器模型

本实验的整数题采用 Data Lab 的 32 位机器模型，而不是以可移植 ISO C 程序为目标：`int` 是 32 位二进制补码；对有符号整数执行 `>>` 时采用算术右移，高位补符号位；加法和左移按 32 位位向量解释，包括左移进入符号位的情况，超出 32 位的高位被丢弃。所有移位量都必须在 0–31 内。构建脚本使用 `-m32 -fwrapv`，提交应以课程提供的 Linux 环境和检查器结果为准。

这个约定对生成最高位掩码、把字节移入最高字节，以及通过低 32 位和进位判断溢出等写法尤其重要。

| 编号 | 函数 | 分值 | 要求摘要 |
|---:|---|---:|---|
| P1 | `signMask` | 1 | 生成符号位掩码 |
| P2 | `bitXor` | 2 | 仅用 `~` 和 `&` 实现异或 |
| P3 | `negativePart` | 3 | 负数返回其相反数，否则返回 0 |
| P4 | `copyByteWithin` | 4 | 将 `x` 的第 `src` 字节复制到第 `dst` 字节 |
| P5 | `roundEvenPow2` | 4 | 舍入到最近的 `2^n` 倍数，正中间时取偶数商 |
| P6 | `isBetweenEitherOrder` | 4 | 判断 `x` 是否位于无序端点 `a`、`b` 构成的闭区间内 |
| P7 | `logicalShift` | 4 | 用算术右移实现逻辑右移效果 |
| P8 | `swapNibblePairs` | 5 | 交换每个字节内的高、低半字节 |
| P9 | `secondLowestZeroBit` | 5 | 标出从低位起第二个 0 位 |
| P10 | `rotateRightBits` | 5 | 32 位循环右移 |
| P11 | `midpointTowardFirst` | 5 | 无溢出计算中点；半整数时选择更靠近第一个参数的相邻整数 |
| P12 | `classifyAdd3` | 7 | 判断三个有符号整数的精确和是否上溢、下溢或可表示 |
| P13 | `mul5Sat` | 7 | 饱和计算 `x*5` |
| P14 | `floatScaleThreeHalves` | 7 | 位级计算单精度浮点数乘 `3/2`，采用最近偶数舍入 |
| P15 | `float_i2f` | 7 | 位级实现 `(float)x` |
| P16 | `floatRoundEven` | 10 | 舍入为最近偶数整数；结果为零时保留输入符号 |
| P17 | `oddParity` | 10 | 计算奇校验位 |
| P18 | `bitCount` | 10 | 统计 1 位个数 |
| P19 | `bitReverse` | 10 | 反转 32 个二进制位 |

更精确的边界条件和示例以 `bits.c` 中对应函数前的注释为准。

## 编译与检查

实验依赖 32 位 GCC 环境。在支持 `gcc -m32` 的 Linux 中执行：

```bash
make clean
make all
./check_ops.py bits.c  # 检查运算符、语法和操作数限制，并显示计数
./btest            # 运行全部正确性测试
./btest -f 函数名  # 只测试一道题
./test.sh          # 一次执行编译、规则检查和总分检查
```

满分输出应包含 `Total points: 110/110`。`test.sh` 只有在编译、运算符检查与全部测试均通过时才返回成功状态。

## 提交前自查

- 只改动 `bits.c` 的函数体，没有改测试器、题面或函数签名。
- `./check_ops.py bits.c` 报告全部函数通过。
- `./btest` 得到 `110/110`。
- 特别检查极值、符号变化、移位 0/31 位、非规格化数、NaN、无穷大和恰好位于舍入中点的输入。
